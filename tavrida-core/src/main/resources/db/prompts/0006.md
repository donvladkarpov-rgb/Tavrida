Необходимо к перевозчику добавить фискализацию.
Схема работы такая:
у перевозчика будет свой фискализатор, в идеале у каждого свой.
В реальности у всех пока только один - бифит.
Когда с терминала перевозчика пачкой (как правило) приходит информация о транзакциях,
перевозчик отправляет сообщения в очередь кафки по каждой транзакции, обогатив эти сообщения
урлом для отправки фискального чека фискальному органу (бифиту), токеном доступа 
(у каждого перевозчика свой), и более того токены могут время от времени меняться, нужно хранить точную дату когда 
он действует и когда заканчивает действие. Сообщения отправляются только с действующим токеном
на дату в время прикладывания карты к терминалу (валидатору). Так же надо сохранять события отправки
фискального чека фискализатору и, самое главное, предусмотреть механизм повторной отправки, если
по каким-то причинам фискализатор не получил информацию и доотправлять ее периодически в течении
какого-то времени. И надо предусмотреть так же вариант когда сообщение вообще не удалось отправить.
Каждый месяц необходимо делать отчет по фискальным чекам для перевозчика.
Надо доделать структуру базы данных для данных сценариев.
