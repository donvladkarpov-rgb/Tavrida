# Оглавление структуры базы данных АСОП

> **Назначение:** Высокоуровневая карта архитектуры базы данных для навигации и планирования детальной документации.  
> **СУБД:** PostgreSQL 14+ с расширением PostGIS

---

## 0. Регионы и Территории (ФИАС/ГАР)
* **`ASOP_REGIONS`** — Справочник регионов на основе данных ФИАС/ГАР для мультирегионального разделения.
* **`ASOP_TERRITORIES`** — Административно-территориальные единицы с гео-полигонами и реквизитами ФИАС.
* **`ASOP_ORGANIZERS`** — Организаторы перевозок.
* **`ASOP_ORGANIZER_TERRITORIES`** — Связь Многие-ко-многим между организаторами и территориями.

## 1. Справочники
* **`ASOP_ROLES`** — Роли доступа в системе.
* **`ASOP_CARD_TYPES`** — Типы провозных носителей.
* **`ASOP_TARIFF_TYPES`** — Типы тарифов.
* **`ASOP_SESSION_TYPES`** — Типы рабочих сессий.
* **`ASOP_EVENT_TYPES`** — Типы системных событий для журнала аудита.
* **`ASOP_TRANSACTION_TYPES`** — Типы финансовых операций.
* **`ASOP_TRANSACTION_RESULTS`** — Результаты выполнения транзакций.
* **`ASOP_SERVICES`** — Классификатор платных услуг ("Услуга" в чеке).

## 2. Маршруты и Пути
* **`ASOP_ROUTES`** — Справочник маршрутов (номер, название, категория).
* **`ASOP_PATHS`** — Физические пути (направления) маршрута с начальной и конечной остановками.
* **`ASOP_FARE_ZONES`** — Тарифные зоны.
* **`ASOP_TRANSPORT_STOPS`** — Справочник остановок общественного транспорта.
* **`ASOP_PATH_TRANSPORT_STOPS`** — Связь Пути и Остановки (порядок следования).
* **`ASOP_SCHEDULE`** — Расписание прибытия на остановки по дням недели.

## 3. Перевозчики, Договоры и ТС
* **`ASOP_CARRIERS`** — Перевозчики (транспортные компании, ГУП, ИП).
* **`ASOP_CARRIER_CONTRACTS`** — Договоры перевозчиков.
* **`ASOP_CONTRACT_ROUTES`** — Связь договора с маршрутами из справочника.
* **`ASOP_VEHICLE_TYPES`** — Справочник типов транспортных средств.
* **`ASOP_VEHICLE_MODELS`** — Справочник моделей транспортных средств.
* **`ASOP_VEHICLES`** — Транспортные средства.

## 4. Пользователи и Безопасность
* **`ASOP_USERS`** — Пользователи системы. ПДн защищены: СНИЛС хэшируется и шифруется, ФИО сокращено, аутентификация через Keycloak.
* **`ASOP_USER_ROLES`** — Связь пользователей и ролей (Многие-ко-многим).
* **`ASOP_USER_CARRIERS`** — Связь пользователей и перевозчиков (Многие-ко-многим).
* **`ASOP_USER_REGIONS`** — Связь пользователей и регионов (Многие-ко-многим).

## 5. Оборудование: Терминалы, TID, Профили, ПО
* **`ASOP_TERMINAL_PROFILES`** — Справочник профилей настроек терминалов.
* **`ASOP_TERMINAL_SOFTWARE`** — Справочник версий программного обеспечения терминалов.
* **`ASOP_TIDS`** — Пул эквайринговых идентификаторов терминалов (TID).
* **`ASOP_TERMINALS`** — Терминалы оплаты и валидаторы. Связь с ТС — через это поле (исторически) и через сессию-рейс.

## 6. Карты, Льготы, Тарифы
* **`ASOP_CARDS`** — Транспортные и банковские карты, зарегистрированные в системе.
* **`ASOP_CARD_MIFARES`** — Технические параметры MIFARE-карт.
* **`ASOP_CARD_BANKS`** — Данные привязанных банковских карт.
* **`ASOP_CARD_TARIFFS`** — Активные тарифы на картах.
* **`ASOP_BLACKLISTS`** — Заблокированные карты.
* **`ASOP_BENEFITS`** — Справочник льготных категорий.
* **`ASOP_BENEFIT_STEPS`** — Шаги накопительных льгот.
* **`ASOP_USER_BENEFITS`** — Привязка льгот к пользователям с датами действия.
* **`ASOP_TARIFF_RATES`** — Тарифные ставки (цены) по зонам, путям и перевозчикам.
### 6.1 Ценообразование
* **`ASOP_PATH_SERVICES`** — Дополнительные услуги на пути. Цена и доступность могут зависеть от перевозчика, ТС или тарифа.
* **`ASOP_PATH_DISCOUNTS`** — Скидки на пути. Поддерживает фиксированные суммы и проценты, может быть уточнена по перевозчику, ТС или тарифу.
* **`ASOP_PATH_BENEFITS`** — Льготы, действующие на конкретных путях.


## 7. Сессии, Транзакции, Аудит, КРС
* **`ASOP_SESSIONS`** — Иерархические сессии. Привязаны к PATH_ID (конкретному пути). ATTRIBUTES хранит контекст.
* **`ASOP_AUDIT_SERVICES`** — Справочник контрольно-ревизионных служб (КРС).
* **`ASOP_AUDIT_TASKS`** — Задания на проведение проверок.
* **`ASOP_AUDIT_TASK_PATHS`** — Список путей, охваченных заданием КРС (1:N).
* **`ASOP_AUDIT_BRIGADES`** — Бригады контролеров, сформированные под задание.
* **`ASOP_AUDIT_BRIGADE_MEMBERS`** — Состав бригады (бригадир и контролеры).
* **`ASOP_AUDIT_INSPECTIONS`** — Акты проведенных проверок. Данные о ТС/терминале/пути вытягиваются из CONTROLLER_SESSION_ID.
* **`ASOP_AUDIT_INSPECTION_TASKS`** — Связь M2M: одна инспекция может быть проведена по нескольким заданиям КРС.
* **`ASOP_TRANSACTIONS`** — Финансовые проводки. METADATA хранит детали расчета (зоны, скидки, льготы).
* **`ASOP_TRANSACTION_CARDS`** — Детализация транзакций по картам.
* **`ASOP_DISPATCH_POSITIONS`** — GPS-трекер транспорта.
* **`ASOP_EVENTS`** — Журнал системных действий и аудит событий.
